# Privacy Policy

API Key Bulk Permissions for Roblox does not collect, store, or share any personal data.

- It runs only on `create.roblox.com/dashboard`.
- It only selects permissions on the Create API Key form. It never reads, saves, or sends your API key.
- Its only network request is an anonymous read (no cookies) of Roblox's public scope list at
  `apis.roblox.com/cloud-authentication/v1/scopes`.
- It has no analytics, no tracking, and no storage.

Questions: https://github.com/brinkokevin/roblox-bulk-perms/issues
